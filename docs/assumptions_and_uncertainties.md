# Допущения и неопределённости

Каждый запуск сохраняет полный список допущений (`run_info.json → assumptions`). Здесь — сводка с оценкой
влияния. **Статус**: S — статистическая, Sys — систематическая (оценена), U — не оценена (нужны данные).

## Численные приближения (проверены)

| Приближение | Проверка |
|---|---|
| Аналитическое ослабление в Be-окнах | явный транспорт: совпадение нерассеянной компоненты; рассеянные в окнах фотоны (окна в метрах до образца) в локальную область практически не попадают |
| Трансляционная инвариантность этапа 1 | независимость от окна; Al явно vs аналитически |
| Отсечение электронов | validate (0.7σ) |
| Принудительное взаимодействие | validate (1.2σ vs аналог) |
| Сетка 0.25–5 мкм | validate (ширина края на сетках 0.25 и 0.5–2 мкм) |
| Переиспользование фазового пространства | предупреждение при кратности > 20 |

## Неопределённости данных Geant4

Коэффициенты ослабления Livermore vs NIST: ≤ 4.8 % (5–30 кэВ). Разброс ЭМ-моделей для дозы ≤ 2 %.
Пороги рождения 100 эВ – 5.6 кэВ: ≤ 0.6 %.

## Нормировка

Абсолютная нормировка независимо подтверждена числами диссертации (3.1 Вт/см² — 0.5 %; 7′45″ — 4 %;
1′45″ — 0.6 %). Остаётся неопределённость экспозиций (мА·мин) и точки отсчёта 20.3 м (±1.5 %).
Расхождение расчётной дозы с табличной минимальной дозой ПММА — см. docs/comparison.md, проблема №6.
