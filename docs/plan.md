## Что запустить тебе (дольше 10 минут)

1. `./run.sh simulate all` — все 22 отверстия, профиль quick (~35 мин).
2. `./run.sh compare` → `./run.sh report` → `./run.sh compare-geant4` (минуты).
3. `./run.sh validate` — полная валидация (~1 ч).
4. Для статьи: `./run.sh simulate all --profile standard` (часы); проверить сходимость окна для
   sapphire_280mm (`--window-extra-mm 0.25 / 1 / 2`).

## Следующие шаги (зависят от данных — docs/questions.md)

1. Калибровка X интерферограмм + карта отверстий → атрибуция кадров, метрология профилей.
2. Единицы аппроксимаций ТЗ → уровень A по-настоящему.
3. Калибровка R(D) → уровень B (leave-one-hole-out).
4. Подложка, зазоры, ориентация шаблона → прогоны чувствительности (параметры уже есть).
5. Оценка брэгговских рефлексов сапфира вне Geant4 (если известна ориентация кристалла).
