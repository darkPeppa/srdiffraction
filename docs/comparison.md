# Сопоставление с экспериментом: анализ и подводные камни

## 1. Что есть в экспериментальных данных

1. **Аппроксимации профилей края** из таблиц техзаданий «К-расчёту-профиля…» — формулы MathType
   (OLE + WMF-превью). Они **извлекаются автоматически из DOCX** (`python/comparison/docx_formulas.py`,
   генерирует `data/experimental_profiles/supervisor_profiles.yaml`). Вид всех формул:

   h(n) = s·(b/π)·atan[ 2π·1.893·(K₁·c − K₂·n) / (a·100) ] + d

   Константы K₁, K₂, d, s различаются между отверстиями (например, сапфир 280 мм, 20 мкм:
   K₁ = 99, K₂ = 81, d = 18; у двух профилей s = −1). Производные величины: центр ступеньки
   n₀ = K₁c/K₂, высота b, ширина перехода 10–90 % **Δn = 2·tan(0.4π)/k ≈ 1.035·a·(50/K₂)**.
2. **106 архивных интерферограмм** (91 JPG + 15 BMP, 1152×864) — скриншоты окна микроинтерферометра
   МИИ-4 / программы MI4 с живым изображением полос (см. docs/interferometry.md).

## 3. Уровень A (реализовано): ширины переходов

`./run.sh compare` → `results/comparison/level_a_comparison.json`, `level_a_widths.png`.
Сравниваются: ширина 10–90 % **дозового** профиля Geant4 и ширина 10–90 % **аппроксимации** ТЗ
(в заявленных мкм). Дополнительно для иллюстрации — ширина нормированного профиля «глубины»
при R ∝ Dᵖ (p = 1…4) без насыщения. **Это не валидация модели**: разные физические величины,
единицы аппроксимаций не подтверждены.

Предварительные числа (quick): дозовые ширины 3–7 мкм; аппроксимации: Be 5.2 (20, 200 мкм) и 29 (300 мкм);
стеклоуглерод 4.1–7.3; сапфир (контакт) 1.5–5.2; сапфир 280 мм 0.15–3.9. Порядок величин совпадает,
но разброс аппроксимаций между отверстиями одного материала (5 → 29 мкм у Be) больше, чем даёт доза —
указание на вклад проявления/наблюдения или на неоднородность обработки.

## 4. Уровень B (каркас): доза → проявление → наблюдение

`python/experimental_interferometry/development_forward.py`:
* вертикальная модель: глубина z, где ∫₀ᶻ dz'/R(D(x,z')) = t_dev (R = 0 → бесконечное время);
* пространственная модель: время прихода фронта T(x,z) из уравнения эйконала |∇T| = 1/R(D)
  (Дейкстра на 16-связной сетке), растворено {T ≤ t_dev} — учитывает боковое проявление.

R(D) — **феноменологические** семейства (сигмоида, степенной закон); параметры не являются свойствами
системы без калибровки. Калибровать — по одним отверстиям/экспериментам, проверять на других
(leave-one-hole-size-out); запрещено подбирать R(D), время и масштаб для каждого отверстия отдельно.

## 5. Чего не хватает для количественного сравнения

1. Калибровка R(D) для сверхмолекулярного ПММА в данном проявителе (скорость растворения vs доза).
2. Горизонтальный масштаб интерферограмм (мкм/пиксель) и карта отверстий на образце.
3. Единицы величин h, b, d и смысл коэффициентов 1.893, 100, 50 в аппроксимациях.
4. Подложка ПММА и толщина напылённого Au.
