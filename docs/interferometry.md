# Независимая обработка интерферограмм ПММА

Подпакет `python/experimental_interferometry` (дополнение к этапу 8). Строго разделяются:
**измерено** (файл, пиксели), **восстановлено** (фаза/высота с неопределённостью), **гипотеза**
(атрибуция кадра), **расчёт** (Geant4 + модель проявления).

## Команды

```
./run.sh inventory-interferograms      # реестр, SHA-256, пары BMP/JPG, перцептивные хэши, контактные листы
./run.sh annotate-roi                  # HTML-инструмент разметки ROI (открыть в браузере)
./run.sh reconstruct-fringes           # методы 1 и 2, QA-панели, таблица профилей
./run.sh validate-supervisor-profiles  # формулы из DOCX → проверки и вердикты
./run.sh assign-mask-features          # гипотезы атрибуции (с достоверностью)
./run.sh compare-geant4                # Geant4 + феноменологическая модель проявления
./run.sh build-interferometry-report   # results/interferometry/interferometry_report.md
```

## Архив

106 изображений (91 JPG + 15 BMP, 1152×864), скопированы без изменений в
`data/experimental_profiles/interferograms/` (папка «Стеклоуглерод», искажённая в архиве кодировкой
CP866, названа `Steklouglerod`; исходное имя записано в реестре). Thumbs.db исключены. SHA-256
совпадают с предоставленным реестром. 14 пар BMP/JPG с одним именем (содержимое сравнивается,
предпочитается BMP); перцептивно похожие кадры отмечаются как кандидаты, но не объединяются.

Большинство кадров — **скриншоты Windows** (окна MI4/ScopePhoto, миниатюры «Кадр №1/№2», обои).
Панель живого изображения находится автоматически (жёлто-зелёная прямоугольная область:
B ≪ G, R ≈ 0.6–1.15·G — отличие от зелёных обоев); найдена на 99/106 кадрах, остальные — «нужна ручная
разметка». Координаты вырезки сохраняются относительно исходного кадра.

## Калибровки

* **Высота:** 0.27 мкм на полный период полос (двойной ход уже учтён; на 2 не делится).
  h − h_ref = (0.27/2π)·(φ − φ_ref).
* **Знак:** не установлен. Знак восстановленной фазы зависит от выбора сопряжённого пика несущей
  (направления наклона опорного зеркала) — доказано синтетическим тестом; выдаются обе ветви.
* **Горизонталь:** независимого масштаба нет → все профили в пикселях, статус
  `lateral_scale_unverified`. Масштаб, полученный по размеру отверстия, программно отклоняется
  (круговая проверка).

## Два метода

1. **Отслеживание полос:** поворот к горизонтальным полосам, субпиксельные минимумы по столбцам,
   непрерывная нумерация порядка от опорной области, Δh = 0.27·δs/p. Полосы не «досчитываются» через
   разрывы.
2. **Фурье (Takeda):** поиск несущей, гауссово окно боковой полосы, обёрнутая фаза + карта модуляции,
   маска качества (абсолютный и относительный порог, блики), разворачивание с сортировкой по
   надёжности (Herráez/scikit-image) по связным валидным областям, вычитание опорной плоскости
   устойчивой регрессией.

Сравнение методов вдоль отслеженных полос (робастная σ разности < 0.1 периода = 0.027 мкм) — иначе
«требует ручной ревизии».

**Принципиальные ограничения** (см. синтетические тесты `tests/test_interferometry_synthetic.py`):
* одиночный кадр — фаза по модулю 2π: ступенька 0.27 мкм неотличима от 0; через крутую стенку
  углубления (до ~55 периодов на 15 мкм) абсолютная глубина **неоднозначна** — выдаётся множество ветвей;
* ступенька ровно π вырождена по знаку (+π ≡ −π);
* наклоны круче полосы пропускания боковой полосы недооцениваются; равномерный наклон неотличим от
  несущей (отсчитывается от плоской опорной области).

## Статусы и вердикты

Статусы кадров: `relative_profile_available` (восстановлена относительная карта высот, X в пикселях),
`needs_manual_roi`, `not_processable`, `processing_error`. **Метрологически достоверных кадров — 0**
до получения калибровки X и разрешения неоднозначности целых периодов.

Аппроксимации руководителя: формулы извлечены из DOCX заново; вердикт по всем — `unverifiable`
(нет атрибуции кадров и калибровки X), с флагами: b > 15 мкм (12 из 16), нестандартные K₁/K₂,
обратный знак, ширина ниже разрешения, отсутствующие/«осиротевшие» формулы.

## Ручная разметка

`./run.sh annotate-roi` → открыть `results/interferometry/roi_editor/index.html` в браузере (работает
офлайн), нарисовать прямоугольники `surface / bottom / left_edge / right_edge / good_fringes / exclude`,
при наличии — масштаб мкм/пиксель **с источником**, Z-координаты из окна прибора. «Сохранить JSON» →
положить файл в `config/interferometry_roi/` → `./run.sh reconstruct-fringes`. Независимая атрибуция
кадров — `config/interferometry_attribution.yaml` (шаблон генерируется командой assign-mask-features).
