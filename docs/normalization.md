# Нормировка и формат результатов

## 1. От тока накопителя к дозе

1. Совместная таблица источника (после Be-окон, аналитически) — фотоны/(с·мрад_гор) в ячейке (E, ψ)
   при опорном токе I_ref = 100 мА: сумма N_θ.
2. Средний по сканированию поток в точке образца: **Φ̇ = N_θ / (L[м] · 2A[мм])** фотонов/(с·мм²)
   (1 мрад по горизонтали ↔ L мм; вертикальный интеграл распределён по пути сканирования 2A = 30 мм).
3. Экспозиция в мА·мин — **интеграл тока по времени**, а не доза: Φ = Φ̇/I_ref · Q[мА·мин] · 60.
4. История этапа 2 представляет один падающий фотон (после Be) на площади окна A_win;
   на этапе 1 вес истории равен доле фотонов, дошедших до плоскости (W/N₁).
5. Доза в ячейке объёма V: **D = (Σ_w E_dep / N₂) · Φ · A_win / V** [Дж/см³]; в Гр — делением на
   плотность ПММА (×10³). Интегральные распределения — ΣE/ΣV (не сумма доз).

Сохраняются одновременно (analysis/summary.json, run_info.json): доза на падающий фотон
(scale_J_per_photon), на единицу флюенса, на экспозицию; абсолютная доза эксперимента.
Абсолютная нормировка подтверждена сверкой с диссертацией (docs/physics_model.md §3).

## 2. Погрешности

По **историям**, не по шагам: в C++ вклад события в ячейку накапливается во временном буфере, в конце
события добавляются x и x². Для колонок (x,y), просуммированных по глубине, хранится отдельная сумма
квадратов (`column_sq`) — точная погрешность глубинно-усреднённых профилей. Для регионов (сумма
колонок) межколоночные корреляции не учитываются; эмпирическая проверка ансамблем независимых зёрен —
в validate. Фазовое пространство этапа 1 переиспользуется с новым положением фотона; при кратности
переиспользования > 20 выдаётся предупреждение (оценка погрешности занижается).

## 3. Трансляционная инвариантность (этап 1 → этап 2)

Al-фильтр и удалённый сапфир — однородные пластины, освещённые широким пучком. Фазовое пространство
в плоскости перед шаблоном/мембраной инвариантно относительно сдвига, поэтому этап 1 стартует из
точки (0,0), а этап 2 назначает фотону положение в окне заново. Конечный «след» пучка учитывается
весом: запись принимается, если |Δx| ≤ 36 мм (полуширина 72 мм) и |y_lab + Δy| ≤ A (сканирование).
Сканируется ли удалённая пластина вместе со сборкой, для бесконечной пластины не важно.

## 4. Форматы (открытые)

* `results/runs/<exp>/hole_<h>um_<profile>/stage2/stage2.h5` (HDF5):
  `/meta` (config_json, geant4_version, seed, n_events, threads, wall_time_s, physics_em),
  `/balance` (энергии, сумма весов, edep_by_role_MeV), `/grids/{map3d,edge_strip}`
  (x/y/z_edges_um, edep_MeV[nx,ny,nz], edep_sq_MeV2, column_sq_MeV2[nx,ny],
  edep_category_MeV[9,…], edep_feature_MeV[12,…], edep_membrane_sq_MeV2; атрибуты имён),
  `/spectra` (e_edges_keV, pmma_entry_weight[3 региона,3 класса,nE], edep_by_primary_energy_MeV,
  region_edep_by_category_MeV), `/slab`, `/phase_space`.
* `run_info.json` — полный провенанс параметров, допущения, нормировка, таймер, окружение.
* Фазовое пространство: бинарные записи 120 байт (little-endian): `e_keV, x_mm, y_mm, dx_mm, dy_mm,
  ux, uy, uz, px, py, pz, w, ylab_mm` (float64) + `flags` (uint32) + `pdg` (int32) + `event` (int64);
  описание дублируется в атрибутах `/phase_space` HDF5. Чтение: `numpy.fromfile(..., dtype=...)`.
* Повтор расчёта: `stage*/stage*.json` — полная разрешённая конфигурация (`liga_sim <json>`).
