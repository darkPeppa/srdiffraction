# Исходные параметры и журнал расхождений

Иерархия источников (ТЗ): **техзадания «К-расчёту-профиля…»** (индивидуальные условия) →
**«Схемы.pptx»** (геометрия, ПММА, вариант Ti) → **диссертация Б.Г. Гольденберга (2011)** (физика
и источник) → проверяемые публикации → **допущения** (только при отсутствии данных, с пометкой).
Машиночитаемая версия — `config/*.yaml` (каждое значение имеет `status` и `source`); в каждом
результате сохраняется полный реестр провенанса (`run_info.json → provenance/assumptions`).

Статусы: **experimental** — техзадание конкретного опыта; **document** — диссертация/презентация;
**assumption** — допущение модели; **unknown** — не установлено.

Порядок слоёв по пучку (по «Схемы.pptx», координаты фигур на слайдах):
**[Be-окна] → Al → (газ) → мембрана → Au (с отверстием) → Ti → каптон → ПММА**. Отверстие есть

`geometry.mask.orientation: ti_upstream` (анализ чувствительности).
