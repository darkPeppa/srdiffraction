# Сохранённые результаты (отслеживаются git)

Рабочий каталог `results/` git игнорирует. Сюда результаты копируются **только** по флагу:

```bash
./run.sh simulate all --persist                    # след прогона и отчёты (лёгкий режим)
./run.sh report --persist --persist-label standard # своя метка снимка
./run.sh validate --persist-heavy                  # + HDF5-карты дозы, PDF, QA-панели (сотни МБ)
```

Каждый снимок — отдельный каталог `<YYYY-MM-DD_HH-MM-SS_UTC>_<метка>/`, внутри — та же структура,
что в `results/`, плюс:

* `README.md` — команда, версия кода (коммит), объём, ссылки на главные отчёты;
* `MANIFEST.json` — все файлы с SHA-256 и все пропущенные файлы с причиной.

**Лёгкий режим** (`--persist`): конфигурации каждого этапа (`stage*/stage*.json` — по ним `liga_sim`
повторяет расчёт тем же зерном), `run_info.json` (параметры, допущения, нормировка, время, версия Geant4),
логи, `analysis/summary.json` и CSV-профили, графики PNG, отчёты Markdown/JSON. Текстовые файлы > 5 МБ
сжимаются gzip.

**Никогда не сохраняются:** фазовое пространство этапа 1 (`*.bin`, сотни МБ, воспроизводимо),
дампы первичных частиц валидации, таблицы источника (`source_table.csv`, пересоздаются).
Файлы > 90 МБ даже после сжатия пропускаются (лимит GitHub).

Снимки не перезаписываются. Ненужный снимок удаляется обычным `git rm -r`.
